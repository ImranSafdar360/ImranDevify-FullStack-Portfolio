# Imran Safdar — Portfolio

Personal portfolio built with Next.js (App Router), Tailwind CSS, and TypeScript.

## Environment

The "Ask my portfolio" AI chat requires a Groq API key. Copy `.env.example` to `.env.local` and set `GROQ_API_KEY` — get a free key at https://console.groq.com.

## Development

```bash
npm install
npm run dev
```
